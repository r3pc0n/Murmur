Murmur Server
Turn this PC into a transcription server

The Murmur Server lets other devices — like your laptop — use this PC's GPU for fast voice transcription.

How it works:

1. Install the server on this PC (one time)
2. Make this PC reachable from your other device
   (local network, Tailscale, or a reverse proxy)
3. In Settings → Transcription, set Mode to Remote
   and enter this PC's URL + the API key

The server runs silently in the background and can be started or stopped from this menu.

This will download ~500 MB of dependencies.
